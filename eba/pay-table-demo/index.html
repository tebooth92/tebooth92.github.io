    Pay Table Layout Options¶

    This page demos four different approaches for displaying pay rate data. Each uses the same DIT Hospital Medical Officers data.

    Option A: Full-Width Tables¶

    Tables stretch wider than normal content. Related links sit above, not beside the table.
